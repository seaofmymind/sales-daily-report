## SCR-001 로그인

| 항목 | 내용 |
|---|---|
| 화면 ID | SCR-001 |
| 화면명 | 로그인 |
| 설명 | 사용자 인증 화면. 이메일/비밀번호로 로그인하며, 인증 성공 시 대시보드로 이동한다. |
| 접근 권한 | 비인증 사용자 |
| URL | `/login` |

### UI 구성 요소

| 컴포넌트 | 유형 | 설명 | 필수 |
|---|---|---|---|
| 이메일 | Input (text) | 등록된 이메일 주소 | Y |
| 비밀번호 | Input (password) | 비밀번호 마스킹 처리 | Y |
| 로그인 버튼 | Button | 폼 제출 및 인증 요청 | - |
| 오류 메시지 영역 | Text | 인증 실패 시 사유 표시 | - |

### 이벤트 / 액션

| 이벤트 | 처리 내용 |
|---|---|
| 로그인 버튼 클릭 | 이메일/비밀번호 유효성 검사 → API 인증 요청 |
| 인증 성공 | 세션 토큰 저장 → SCR-002로 이동 |
| 인증 실패 | 오류 메시지 표시 ("이메일 또는 비밀번호가 올바르지 않습니다") |
| Enter 키 | 로그인 버튼 클릭과 동일하게 처리 |

### 유효성 검사

- 이메일: 이메일 형식 (`RFC 5322`)
- 비밀번호: 1자 이상 입력 필수

## SCR-004 일일 보고서 작성/편집

| 항목 | 내용 |
|---|---|
| 화면 ID | SCR-004 |
| 화면명 | 일일 보고서 작성 / 편집 |
| 설명 | 영업 사원이 오늘의 방문 기록과 Problem / Plan을 작성하는 메인 입력 화면. 행 단위로 방문 내용을 추가할 수 있다. |
| 접근 권한 | 영업 사원 (본인 보고서, 당일 한정) |
| URL | `/reports/new`, `/reports/{id}/edit` |

### UI 구성 요소

#### 헤더 영역

| 컴포넌트 | 유형 | 설명 |
|---|---|---|
| 보고 날짜 | Text (읽기 전용) | 오늘 날짜 자동 설정 |
| 작성자 | Text (읽기 전용) | 로그인 사용자명 |
| 상태 배지 | Badge | DRAFT / SUBMITTED |

#### 방문 기록 섹션

> 1일 N건 추가 가능. 행 단위로 관리한다.

| 컴포넌트 | 유형 | 설명 | 필수 |
|---|---|---|---|
| 고객명 | Select (검색형) | 고객 마스터에서 검색 선택 | Y |
| 방문 시각 | Time Picker | `HH:mm` 형식 | N |
| 방문 내용 | Textarea | 상담 내용, 미팅 결과 등 자유 기술 | Y |
| 결과 | Textarea | 계약 여부, 후속 조치 등 | N |
| 행 삭제 버튼 | Icon Button | 해당 행 삭제. 최소 1행 유지 | - |
| 행 추가 버튼 | Button | 방문 기록 행 추가 | - |

#### Problem (현안 / 과거 상담) 섹션

> 1일 N건 추가 가능.

| 컴포넌트 | 유형 | 설명 | 필수 |
|---|---|---|---|
| 내용 | Textarea | 현재 겪고 있는 문제, 과거 상담 사항 자유 기술 | Y |
| 행 삭제 버튼 | Icon Button | 해당 항목 삭제 | - |
| 항목 추가 버튼 | Button | Problem 항목 추가 | - |

#### Plan (내일 할 일) 섹션

> 1일 N건 추가 가능.

| 컴포넌트 | 유형 | 설명 | 필수 |
|---|---|---|---|
| 내용 | Textarea | 내일 방문 예정 고객, 처리 예정 업무 자유 기술 | Y |
| 행 삭제 버튼 | Icon Button | 해당 항목 삭제 | - |
| 항목 추가 버튼 | Button | Plan 항목 추가 | - |

#### 하단 액션 영역

| 컴포넌트 | 유형 | 설명 |
|---|---|---|
| 임시저장 버튼 | Button (Secondary) | DRAFT 상태로 저장 |
| 제출 버튼 | Button (Primary) | SUBMITTED 상태로 저장. 제출 후 편집 불가 |
| 취소 버튼 | Button (Ghost) | 이전 화면으로 이동 (미저장 경고 표시) |

### 이벤트 / 액션

| 이벤트 | 처리 내용 |
|---|---|
| 행 추가 클릭 | 빈 입력 행을 목록 맨 아래에 추가 |
| 행 삭제 클릭 | 해당 행 제거. 방문 기록은 최소 1행 유지 |
| 고객명 검색 | 2글자 이상 입력 시 고객 마스터 자동완성 팝업 표시 |
| 임시저장 클릭 | 유효성 검사 (필수 항목) → API 저장 → 성공 토스트 메시지 |
| 제출 클릭 | 유효성 검사 → 제출 확인 모달 표시 → 확인 시 API 제출 → SCR-005로 이동 |
| 취소 클릭 | 변경사항 있을 경우 "저장하지 않고 나가시겠습니까?" 확인 모달 표시 |
| 페이지 이탈 (브라우저) | 임시저장 유도 confirm 다이얼로그 표시 |

### 유효성 검사

- 방문 기록: 최소 1행 이상, 각 행의 고객명/방문 내용은 필수
- Problem/Plan: 항목이 있는 경우 내용 필수 (빈 항목 제출 불가)
- 제출 상태 보고서: 이후 편집 버튼 비활성화
